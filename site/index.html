Prove only what a game needs to know.

GDW is a small, dependency-free toolkit that brings selective-disclosure credentials to game developers. A player's credential is signed once, and a game server can later ask for a single fact — “over 18”, “owns the Season Pass” — without learning anything else.

What it is for

The same audience–friendly model that a wallet uses for identity documents, adapted to the everyday needs of online games.

Age gating & matchmaking

Prove “over 18” without revealing a birth date.

Portable entitlements

A season pass that works across titles and platforms, without a central account call on every launch.

Guild membership & rank

Verifiable membership a third-party tournament server can trust.

Tournament passes

Time-boxed, non-transferable entry proofs bound to a device.

Verified accounts

Prove control of a platform identity, once.

Parental consent

Prove a guardian-consent claim is present and valid.

Seven languages, one token format

Every port replays the same cross-language test vectors. If all of them pass, the credentials are byte-for-byte identical — so a game client, a game server, and a backend can all speak it.

Get started in three steps

The JavaScript / TypeScript port ships as an npm package; the others live in the repository.

  1. Install

    No runtime dependencies. TypeScript declarations are included.

    npm install @arasbutauskas/gdw-game-wallet

  2. Issue, present, verify

    An issuer signs a credential; a wallet reveals only what is asked for; a verifier checks it.

    // issue a credential with selective claims
const issuer   = new Issuer(issuerKey, 'https://issuer.example/age');
const credential = issuer.issue({
  vct: 'urn:eudi:game:attestation:age-over-18',
  claims: { nickname: 'player42', age_over_18: true, country: 'LV' },
  disclosable: ['nickname', 'age_over_18', 'country'],
});

// the wallet discloses a single claim
const wallet = new Wallet(holderKey);
const presentation = wallet.present(credential, ['age_over_18']);

// the verifier checks the presentation
const result = verifier.verify(presentation, { claims: { age_over_18: true } });
// => { age_over_18: true }

  3. Try the other ports

    Each language has its own folder, README, and test runner in the repository.

    git clone https://github.com/abutauskas/gdw-game-wallet-frameworks
cd gdw-game-wallet-frameworks && make test

Specification & test vectors

The token format is defined in SPEC.md. The vectors are generated by test-vectors/generate_vectors.py — the executable form of the specification — and every framework must pass them byte-for-byte.

Read SPEC.md Browse the vectors

Prototype, not a standard

The default algorithm is HS256 (symmetric HMAC), which is only safe when the issuer and the verifier are the same trusted backend. This project is not an official EU specification and is not interoperable with production EUDI Wallets.
